# Specs

One document per Goal.
The file is created automatically when the Goal is opened,
named from the Goal title, and carries the Goal in its frontmatter.

## Trial Goals

A candidate is handed the Goal labelled with the position they applied for,
the moment their profile pull request merges.
These stay open and are edited as the business changes,
because every candidate runs their own copy.
How a candidate runs one is in [how the trial runs](../trial.md).
