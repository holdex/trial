# Marketing Framework

## Overview

Holdex sells services that need explaining before they can be bought.
This Goal is the framework for finding the people worth explaining them to.

## Objective

Define how Holdex acquires a qualified lead for one of its services, end to end,
and draft the material that framework would run on.

## Choosing the service

Inspect the brand, then pick a single Holdex service to build the framework
around.

## Qualifying a lead

Describe what makes a lead qualified for that service,
and how you would establish it.

## The framework

Ten steps, from first contact to a qualified lead.

## The collateral

A draft of the marketing material your framework calls for,
far enough along to judge.

## Deliverables

One Google Doc holding the framework and the collateral,
shared so the reviewers can comment on it.
